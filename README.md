## GitHub Pages 게시

1. dandelionmedia 계정에서 공개 저장소 `yussam-prompt-pack`을 만듭니다.
2. 이 ZIP을 압축 해제한 뒤 `index.html`, `prompts.js`, `profile-kim-yuseong.jpg`, `.nojekyll`, `README.md`를 저장소 최상위에 올립니다. ZIP 파일 자체를 올리지 마세요.
3. Settings → Pages → Source에서 Deploy from a branch를 선택합니다.
4. Branch는 main, 폴더는 /(root)를 선택하고 Save를 누릅니다.
5. GitHub 게시가 완료되면 https://dandelionmedia.github.io/yussam-prompt-pack/ 에서 확인합니다.

별도 설치나 빌드가 필요하지 않습니다. 검색·분야별 목록·173개 상세 보기·복사·지시서 만들기 기능을 포함합니다. 상세 화면은 # 주소로 열려 새로고침해도 별도 서버 설정이 필요하지 않습니다.
